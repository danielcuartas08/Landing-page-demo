# 🚀 Slick - Landing Page Demo

Este repositorio es una demostración de maquetación web y despliegue en tiempo real utilizando **GitHub Pages**. Corresponde a una landing page moderna e interactiva adaptada para dispositivos móviles y de escritorio.

🔗 **Ver sitio desplegado:** [Demo en vivo en GitHub Pages](https://danielcuartas08.github.io/slick-landing-page/)

### 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructuración semántica de la interfaz.
* **CSS3:** Estilos visuales, degradados, animaciones y diseño responsivo.
* **JavaScript:** Interactividad en el menú navegación y componentes.
* **GitHub Pages:** Servidor de despliegue continuo para el proyecto.

### 📂 Estructura del Proyecto

* `/css` - Hojas de estilo generales y de diseño responsivo.
* `/js` - Scripts de interacción de la landing page.
* `/img` - Recursos multimedia e imágenes.
* `index.html` - Documento principal.
